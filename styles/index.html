Spatial Interaction

Hand-tracking gestures replace traditional touch input in this AR interface, letting users interact with virtual objects as naturally as physical ones. The challenge was designing for a 6DoF space with no established conventions.

Feature (image right, flipped)

Onboarding Flow

A progressive disclosure onboarding that surfaces complexity only when users are ready for it. First-session completion rate increased from 61% to 88% after this redesign.

Feature (ratio opt-out)

Wide Media

Feature media defaults to a 4:3 crop so mixed sources sit evenly beside one another. Pass ratio (any CSS aspect ratio) to opt out when cropping would cut content — wide footage, diagrams, screenshots. Mirrors BentoGrid’s ratio prop. The optional caption renders beneath the media and supports inline markdown links.
